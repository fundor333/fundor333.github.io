The theme uses **six roles**: Primary (violet), Content, Links (green), Visited,
Background, Inactive. Surfaces and borders are mixes of Content over Background,
so no extra hue enters the *chrome*.

An unvisited link is **green**; a [visited link](#) is lavender; on `:hover` it
turns violet. Every text pairing clears WCAG AA, and body text and code reach
AAA.
